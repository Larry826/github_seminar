# 확정 커리큘럼 (90분)

| 시간 | 내용 | 핵심 설명 및 확인 |
|---|---|---|
| 0–10분 | Git과 GitHub 차이, Git을 쓰는 이유 | Git은 내 컴퓨터의 변경 이력 관리 도구, GitHub는 원격 저장소와 협업 서비스. 저장과 커밋의 차이 |
| 10–20분 | GitHub 기본 화면 및 VS Code 연동 | 저장소의 Code, Commits, Branch, Pull requests, Issues; VS Code 폴더 열기와 Source Control |
| 20–40분 | 개인 프로젝트 생성 및 첫 Commit | ZIP을 풀어 폴더를 열고 Git 확인·init·stage·commit·log. 로컬 사용자 정보 |
| 40–55분 | 개인 프로젝트 GitHub 업로드 및 수정 | TODO 1 수정과 diff·commit 후 빈 Public 저장소 생성·push·웹 확인 |
| 55–75분 | 개인 Branch 생성, 작업, Merge 실습 | feature/profile에서 TODO 2, push, 자기 저장소 PR, merge, main pull·이력 확인 |
| 75–80분 | 팀 프로젝트 협업 방식 맛보기 | 브랜치·PR 리뷰, Issue, Fork, 충돌 해결 시연 |
| 80–90분 | GitHub 신기한 꿀팁 시연 | 공개 저장소로 다섯 URL 변환과 github.dev; 서비스별 한계 및 정보 보호 |

단계별 지시는 `PRACTICE_STEPS.md`, 정답은 `SOLUTION_GUIDE.md`, 향후 슬라이드 계획은 `PRESENTATION_NOTES.md`를 사용한다. 학생에게 미리 정답을 배포하지 않는다.
