# GitHub URL 꿀팁 원고

공개 예시 `https://github.com/OWNER/REPO`의 호스트만 바꾼다. OWNER/REPO는 실제 공개 저장소로 교체한다. 다음 설명은 연결된 공식 문서와 프로젝트 설명을 참고한 것이며, **각 서비스의 실제 저장소 변환·실행을 이번 작업에서 직접 검증하지 않았다**. 접속, 지원 범위, 요금과 화면은 바뀔 수 있다.

| 주소 | 용도 | 한계 |
|---|---|---|
| `https://gitdiagram.com/OWNER/REPO` | 저장소 구조를 AI 다이어그램으로 파악 | 일부 파일만 분석할 수 있고 누락·오류가 있으므로 원본으로 확인. 코드 실행 도구가 아님. [설명](https://gitdiagram.com/visualize-codebase) |
| `https://gitingest.com/OWNER/REPO` | 파일 구조와 내용을 텍스트 요약물로 모아 살펴보기 | 크기·필터 등으로 내용이 빠질 수 있음. 코드를 실행하거나 정확성을 보증하지 않음. [프로젝트](https://github.com/coderamp-labs/gitingest) |
| `https://githubbox.com/OWNER/REPO` | CodeSandbox에서 지원되는 프로젝트를 열어 편집·미리보기 시도 | 모든 저장소가 즉시 실행되는 것은 아님. 환경·의존성·설정과 서비스 지원 여부에 좌우됨. |
| `https://github.dev/OWNER/REPO` | 브라우저 VS Code 편집기로 파일 탐색·수정·커밋. GitHub 저장소 화면에서 `.` 키도 가능 | 서버나 터미널에서 코드 실행은 지원하지 않음. 키보드 배치에 따라 단축키가 안 될 수 있음. [GitHub 문서](https://docs.github.com/en/codespaces/the-githubdev-web-based-editor) |
| `https://github1s.com/OWNER/REPO` | 브라우저의 VS Code 스타일로 저장소 코드 탐색 | 실행 환경이 아니며 편집·저장 기능은 제한적. [프로젝트](https://github.com/conwnet/github1s) |

GitHub 외 서비스는 제3자에게 저장소 주소나 내용을 전달할 수 있다. 공개 예제만 시연하고, 비공개 코드·개인정보·비밀키는 권한과 서비스 정책을 확인하기 전 입력하지 않는다. AI 분석 결과와 복사한 내용의 정확성은 직접 검토한다.
